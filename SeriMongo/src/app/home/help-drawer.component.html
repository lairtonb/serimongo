Ajuda - SeriMongo

Manual do usuário

Visão geral

Inspecione logs em tempo real ou em uma busca estável.

O SeriMongo combina Tail via SignalR, busca LogQL, filtros rápidos e detalhes estruturados para analisar eventos sem sair da tela.

Fluxo principal

Use os filtros e a query para reduzir o conjunto, selecione uma linha para abrir os detalhes e copie o que precisar para incidentes, PRs ou tickets.

Busca

Campo LogQL e ação Search

Digite uma expressão LogQL no campo principal. Ao clicar em Search, o Tail é pausado e a tela carrega uma página estável de resultados.

O painel Effective query mostra a query final gerada pela união da expressão digitada com período, level e service selecionados.

LogQL

Sintaxe suportada

Campos

id, timestamp, time, level, message, renderedmessage, exception, service, servicename, service.name.

Propriedades

Use prop.<name>, property.<name> ou properties.<name> para campos estruturados. Caminhos com ponto são suportados.

Operadores

=, !=, >, >=, <, <=, contains, startswith, endswith, in (...) e exists.

Booleanos

Combine condições com and, or e parênteses.

level = Error
level in (Warning, Error, Fatal)
message contains "timeout"
message startswith "checkout"
exception contains "OutOfMemoryException"
serviceName = "checkout-api"
timestamp >= "2026-06-25T12:00:00Z"
prop.TraceId = "abc123"
prop.exception.type exists
prop.DurationMs > 500
(level = Error or level = Fatal) and serviceName = "worker"

Filtros rápidos

Período, level e service

Os filtros rápidos montam cláusulas LogQL automaticamente. Período gera uma condição em timestamp; levels selecionados geram level in (...); services selecionados geram serviceName in (...).

O botão Clear limpa os filtros rápidos, mantendo a expressão digitada no campo LogQL.

Tabela

Linhas, colunas e seleção

A tabela é virtualizada para manter a interface leve com muitos logs. Clique em uma linha para abrir o painel de detalhes.

O botão de colunas permite mostrar ou ocultar TraceId, Timestamp, Level, Service e Message. Pelo menos uma coluna permanece visível.

Detalhes

Evento selecionado

O painel lateral mostra message, timestamp, service, id, exception e properties. A divisória entre tabela e detalhes pode ser arrastada para ajustar a largura.

Ao selecionar uma linha, o Tail é pausado para evitar que novos eventos mudem o contexto enquanto você analisa o registro.

Copiar

Clipboard e Markdown

Use o botão de copiar no header dos detalhes para exportar o evento como Markdown. Os botões em Message e Exception copiam apenas aquele bloco.

Ao copiar, um toast aparece no canto inferior direito confirmando sucesso ou falha.

Tail

Pause e retomada

Pause não desconecta o SignalR. Ele apenas envia o estado de pausa para o hub e bloqueia novos eventos na tela.

Depois de pausado, o botão volta a mostrar Tail. Clicar nele reativa o Tail na mesma conexão SignalR e sincroniza a query atual com o hub.
