Use LogQL to combine direct fields, structured properties, text search and time windows.

Fields

id, timestamp, level, message, exception, serviceName, and prop.<name> for structured properties.

Operators

=, !=, >, >=, <, <=, contains, startswith, endswith, in (...), and exists.

Boolean logic

Use and, or, and parentheses to group conditions.

Strings and dates

Quote strings with spaces. Use ISO timestamps like 2026-06-25T12:00:00Z.

Property fields

Use prop., property., or properties.. Path segments may use letters, numbers, _ and -; dotted paths are supported.

Examples 
level = Error
level in (Warning, Error, Fatal)
message contains "timeout"
message startswith "checkout"
exception contains "OutOfMemoryException"
serviceName = "checkout-api"
timestamp >= "2026-06-25T12:00:00Z"
prop.TraceId = "abc123"
prop.exception.type exists
prop.DurationMs > 500
(level = Error or level = Fatal) and serviceName = "worker"
